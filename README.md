VU Kursinio darbo dalis - nuotoliu valdoma mašinėlė, paremta Raspberry Pi.

Kodas paremtas dabar jau mirusiu karkasu - Xamarin. Šioje repozitorijoje yra mašinėlės pultelio kodas, aplikacijos forma.

2025 padarau open-source, galbūt kam nors pagelbės. Gal. :)

Mašinėlėje veikiantį kodą (serverį) galima pasiekti čia: https://github.com/Evaldash/kursinis-pi
